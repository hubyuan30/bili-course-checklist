# B 站网课待办清单（PDF / HTML）

把一门 B 站课程变成一张能打印、能打勾的学习进度表。抓分P标题和时长 → 按教材结构分章 → 统计章内累计时长 → 输出 PDF 和/或单文件 HTML。

## 输入

| 项 | 必需 | 说明 |
|---|---|---|
| 视频链接 / BV 号 | 是 | 合集里的单集也可以，会自动取整个合集 |
| 输出格式 | 否 | PDF、HTML，或两者都要（默认两者都出） |
| 分章偏好 | 否 | 想怎么分章；不说就按教材知识结构归纳 |
| 略去哪些分P | 否 | 如推广、插曲、结语；默认会主动识别并略去非教学分P |
| 文件名 | 否 | 默认 `科目-老师-网课清单` |

## 输出

| 文件 | 形态 | 说明 |
|---|---|---|
| `科目-老师-网课清单.pdf` | A4 打印版 | 六列表格，纯黑白，「完成」「完成时间」留空手写 |
| `科目-老师-网课清单.html` | 单文件网页 | 同样六列，可点选打勾；勾上自动写入完成时间，取消即清空；自动统计总进度和每章进度；数据存本地浏览器 |

两个文件共用同一份课程数据（`checklist_data.py` 里的 `CONFIG` 与 `CHAPTERS`），改一次即可同时更新。

## 输出长什么样

表格六列，顺序固定：

| 编号 | 课程内容 | 时长 | 本章累计（到本节上完） | 完成 | 完成时间 |
|---|---|---|---|---|---|
| 3 | 本征半导体、杂质半导体 | 38:26 | 38 min |  |  |
| 4 | PN结的形成与半导体二极管 | 56:19 | 1 h 34 min |  |  |

- **时长**：`mm:ss`，取自 B 站接口，不在本地估算
- **本章累计**：本章第一节到本节上完的累计时长，英文单位、只到分钟（`38 min` / `1 h 34 min`）
- **完成**：PDF 留空手写打勾；HTML 是可点的方框
- **完成时间**：PDF 留空手写；HTML 勾选时自动写入 `YYYY-MM-DD HH:MM`，取消勾选即清空
- 章标题加粗跨列，带 `共 N 讲 · X 小时 Y 分`；每页重复表头，章标题不会孤零零落在页脚
- HTML 正文黑白，只用深墨绿 `#2a6249` 做进度强调，打印时自动转黑

## 用法

1. 把 [SKILL.md](SKILL.md) 里的两段代码模板复制出来，分别存成 `make_todo_pdf.py` 和 `make_todo_html.py`
2. 新建 `checklist_data.py`，填入 `CONFIG`（标题、UP 主、输出文件名等）和 `CHAPTERS`（章节与课时数据）
3. 安装依赖并运行：

```bash
pip install reportlab          # 只出 HTML 的话不需要
python make_todo_pdf.py        # 生成 PDF
python make_todo_html.py       # 生成 HTML
```

数据怎么抓（B 站接口、合集 `ugc_season` 分支、秒数校验）、怎么分章、以及排版踩过的坑，都写在 [SKILL.md](SKILL.md) 里，建议一起看。

## 示例

`examples/` 下是同一门课的两个产出，可以对照看：

- [模电-姬清影-网课清单.pdf](examples/模电-姬清影-网课清单.pdf) —— 8 页，打印用
- [模电-姬清影-网课清单.html](examples/模电-姬清影-网课清单.html) —— 双击打开，可直接勾选打卡

课程：模拟电子技术基础（姬清影_），164 讲 / 92 小时 30 分，原视频 166 个分P，略去了「插曲」「结语」两个非教学分P。

## 依赖

- Python 3
- [`reportlab`](https://pypi.org/project/reportlab/)（仅 PDF 需要）
- 中文字体：Windows 自带的 `msyh.ttc` / `msyhbd.ttc`（缺失时回退 `simsun.ttc` / `simhei.ttf`）
- HTML 无任何外部依赖，单文件离线可用

## 目录

```
SKILL.md        # 完整说明 + PDF / HTML 两套可运行代码模板
examples/       # 同一门课的 PDF 与 HTML 成品
```

## 备注

- 课程标题、单节时长全部来自 B 站 `view` 接口，不编造；生成后会用接口返回的总秒数做一次校验
- 非教学分P会被略去，并在页脚注明
- 原视频没有官方章节，章节是按分P标题归纳的，页脚也会写明
