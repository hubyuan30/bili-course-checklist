# B 站网课待办清单 PDF

把一个 B 站课程链接，变成一张**黑白可打印、可以逐节打勾**的学习进度表（PDF）。

抓分P标题和时长 → 按教材结构分章 → 统计章内累计时长 → 按页精确分页输出。

## 输出长什么样

表格六列，顺序固定：

| 编号 | 课程内容 | 时长 | 本章累计（到本节上完） | 完成 | 计划时间 |
|---|---|---|---|---|---|
| 3 | 本征半导体、杂质半导体 | 38:26 | 38 min |  |  |
| 4 | PN结的形成与半导体二极管 | 56:19 | 1 h 34 min |  |  |

- **时长**：`mm:ss`，取自 B 站接口，不在本地估算
- **本章累计**：本章第一节到本节上完的累计时长，英文单位、只到分钟（`38 min` / `1 h 34 min`）
- **完成 / 计划时间**：留空，手写打勾与日期
- 纯黑白，章标题加粗跨列并带 `共 N 讲 · X 小时 Y 分`，每页重复表头，章标题不会孤零零落在页脚
- 文件名统一：`科目-老师-网课清单.pdf`

## 用法

1. 把 [SKILL.md](SKILL.md) 里的代码模板复制出来，存成 `make_todo_pdf.py`
2. 改文件顶部的 `CONFIG`（标题、UP 主、输出文件名）和 `CHAPTERS`（章节与课时数据）
3. 安装依赖并运行：

```bash
pip install reportlab
python make_todo_pdf.py
```

数据怎么抓（B 站接口、合集 `ugc_season` 分支、秒数校验、分章规则、分页坑）都写在 [SKILL.md](SKILL.md) 里，建议一起看。

## 示例

[模电-姬清影-网课清单.pdf](examples/模电-姬清影-网课清单.pdf) —— 模拟电子技术基础（姬清影_），164 讲 / 92 小时 30 分，8 页。

这份是当前列规范的参考产出：六列表格、章内累计用 `h / min`、完成列留空待手写。

## 依赖

- Python 3
- [`reportlab`](https://pypi.org/project/reportlab/)
- 中文字体：Windows 自带的 `msyh.ttc` / `msyhbd.ttc`（缺失时回退 `simsun.ttc` / `simhei.ttf`）

## 目录

```
SKILL.md        # 完整 skill 说明 + 可运行代码模板
examples/       # 参考产出（1 份）
```

## 备注

- 课程标题、单节时长全部来自 B 站 `view` 接口，不编造；生成后会用接口返回的总秒数做一次校验
- 非教学分P（推广、插曲、结语）会被略去，并在页脚注明
- 原视频没有官方章节，章节是按分P标题归纳的，页脚也会写明
